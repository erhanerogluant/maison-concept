# Maison AUREL — restaurant website design concept

Live: **https://erhanerogluant.github.io/maison-concept/**

A design concept for **Maison AUREL**, a fictional contemporary fine-dining restaurant in Berlin.
Menus, prices and details are illustrative; no bookings are taken.

This repository contains only the compiled static site served by GitHub Pages. The source code
is not public.
